# Blog Edit: Clarity (phase 2)

Every paragraph earns its place. Read-only pass; proposes, never edits.

## Process

1. Read the draft and `points.log`.
2. For each paragraph, state in one line what point it delivers. If you cannot, flag it.
3. Flag **back-and-forth**: two points braided without signaling, so the reader loses one thread.
4. Flag **rambling**: sentences or paragraphs that promise a payoff and never deliver. Dangling praise ("the commentary is enlightening") with no follow-up is the canonical case.
5. Flag **crowding**: one paragraph doing three jobs.
6. Give every flag a proposed disposition: keep, cut, merge, split, move, or develop.
7. Write `clarity.log` with finding ids (F01, F02, ...) so later passes can reference them.

## Worked example

From notes/blog/20260806_: "The proof itself is irrelevant to a general audience, but the commentary of the authors on their thoughts about AI and math is very enlightening." Promises a payoff that never comes. Disposition: cut or develop.

## Edge cases

- Deliberate ambiguity and open questions are not rambling; check the standing aim before flagging.
- A short stylistic interjection (a joke, an aside) is a side point, not a clarity problem, unless it undercuts the register.
